# Using this folder

If you don't have **DVC** Visit https://www.dvc.org and follow instllation guide. Or you can just follow the following steps.
- Visit https://doc.dvc.org/install/windows if you windows computer and take a look at the docs.
- Open PS as administrator (optional) but you might get some problems if you don't.
- If you have winget run the following code `winget install --id Iterative.DVC`
- Restart PS
- Go to the working directory using `cd work_dir`
- Run the following code: `dvc init`
- If you have written your code for `.py` and `.yaml` you can run `dvc prod`
- For more commands you might have to visait the official website: https://doc.dvc.org
